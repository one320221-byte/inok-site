Как установить

  1. Скачайте и распакуйте архив

    Нажмите «Скачать расширение», затем распакуйте zip. Появится папка inok-extension. Положите её туда, где она не потеряется: браузер берёт расширение прямо из неё.

  2. Откройте страницу расширений

    Скопируйте адрес и вставьте его в адресную строку браузера.

  3. Включите «Режим разработчика»

    Переключатель в правом верхнем углу страницы расширений.

  4. Нажмите «Загрузить распакованное»

    Выберите папку inok-extension. Значок INOK появится рядом с адресной строкой; закрепите его кнопкой с пазлом.

  5. Введите ключ

    Ключ в боте: «🧩 Расширение для Chrome». Нажмите на значок INOK, вставьте ключ, и свеча загорится.

Важно знать

Это защищает весь компьютер?

Нет, только браузер. Для всех программ и телефона используйте приложение по ссылке-подписке из бота.

Почему не из магазина Chrome?

Мы готовим публикацию в Chrome Web Store. Пока расширение ставится вручную, это безопасно: весь код открыт в папке, которую вы скачали.

Браузер пишет про режим разработчика

Так Chrome предупреждает обо всех расширениях не из магазина. Закройте подсказку: расширение продолжит работать.

Сколько стоит?

Ничего дополнительно. Ключ работает, пока активна ваша подписка INOK. Не передавайте его другим: ключ привязан к вашему аккаунту.
